# 데이터 테이블 명세 (CSV)

> 스테이지 목록, 몬스터 배치처럼 **행을 추가하며 늘어나는 데이터**는 CSV 테이블로 관리한다.
> 이 문서는 테이블 구조의 기준이다. 컬럼을 추가하거나 바꾸면 이 문서도 같은 PR에서 고친다.
> 왜 CSV를 쓰는지는 [`decisions/002-stage-data-csv.md`](decisions/002-stage-data-csv.md) 참고.

## 1. 공통 규칙

### 위치와 로드
- 파일 위치: `Assets/_Project/Resources/<테이블명>.csv`
- 로드: `Resources.Load<TextAsset>("<테이블명>")` (확장자 없이)

### 파일 형식
- 인코딩: **UTF-8** (한글 포함)
- 첫 줄은 **헤더(컬럼 이름)**, 둘째 줄부터 데이터
- 구분자: 쉼표 `,`
- **값 안에 쉼표를 쓰지 않는다.** (따옴표 처리 없이 단순 분리로 읽기 위함)
- 빈 줄은 무시한다.

### 컬럼 이름 규칙
- PascalCase (예: `StageName`, `TimeLimit`)
- 고유 식별자는 `<테이블명>Id` (예: `Stage` 테이블 → `StageId`)
- 다른 테이블을 참조하는 컬럼(외래키)은 **참조 대상의 Id 컬럼 이름을 그대로** 쓴다.
  (예: `StageMonster.StageId` → `Stage.StageId`)

### 컬럼을 추가·변경할 때
- **로더는 컬럼을 순서가 아니라 헤더 이름으로 찾는다.** 그래서 새 컬럼은 어느 위치에 넣어도 기존 코드가 깨지지 않는다.
- 새 컬럼은 **기본값**을 함께 정하고 이 문서에 적는다. (기존 행에 값이 비어 있어도 동작하도록)
- 컬럼 **이름 변경과 삭제**는 코드에 영향을 주므로, 사용하는 코드를 확인하고 상대에게 알린 뒤 진행한다.

### ⚠️ 엑셀로 편집할 때
- 저장할 때 **"CSV UTF-8(쉼표로 분리)"** 형식을 고른다. 그냥 "CSV"로 저장하면 한글이 깨진다.
- 엑셀의 CSV UTF-8 형식은 파일 맨 앞에 BOM(보이지 않는 문자)을 붙인다. 로더는 첫 헤더에서 BOM(`﻿`)을 제거해야 한다.
- 엑셀이 숫자 형식을 바꾸는 경우가 있다 (예: `01` → `1`). Id는 숫자로만 쓴다.

## 2. Stage

스테이지 목록. 스테이지 선택 UI가 `StageId`로 `SceneName`을 찾아 씬을 로드한다.
`StageMonster` 등 다른 테이블이 `StageId`를 참조하므로 **가장 먼저 정의되는 기준 테이블**이다.

- 파일: `Assets/_Project/Resources/Stage.csv`

| 컬럼 | 타입 | 필수 | 설명 | 규칙 |
|---|---|---|---|---|
| `StageId` | int | ✅ | 스테이지 고유 식별자 | 1 이상, 중복 금지. 한번 정한 Id는 바꾸지 않는다 (다른 테이블이 참조함) |
| `SceneName` | string | ✅ | 로드할 Unity 씬 이름 | 확장자 없이 씬 파일 이름과 정확히 일치. **Build Profiles의 Scene List에 등록돼 있어야** 로드 가능 |
| `StageName` | string | ✅ | 게임 안에 표시할 이름 | 쉼표 금지 |

### 현재 데이터
`Stage01~03` 씬과 `스테이지 1~3` 이름은 **자리 표시용**이다. 실제 씬을 만들면 이름을 맞추고, 표시 이름은 기획에 맞게 바꾼다.

### 추가 예정 컬럼 (미확정)
| 컬럼 | 타입 | 기본값(안) | 설명 |
|---|---|---|---|
| `Bgm` | string | 빈 값 = BGM 없음 | 재생할 BGM 리소스 이름 |
| `TimeLimit` | float | 0 = 제한 없음 | 제한 시간(초) |

### 스테이지 추가 방법
1. 새 씬을 만들고 Build Profiles의 Scene List에 등록한다.
2. `Stage.csv`에 한 줄 추가한다. (`StageId`는 기존 최댓값 + 1 권장)
3. 코드 수정은 필요 없다.
