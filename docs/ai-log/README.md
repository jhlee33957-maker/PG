# AI 실험 로그

AI와 일하면서 생긴 **시행착오와 배운 점**을 남기는 곳이다.
PR 템플릿이 "이번 작업에서 AI가 한 것"이라면, 이 로그는 "AI와 일하는 방식이 어떻게 나아졌는가"를 기록한다.

## 언제 쓰나 (모든 PR마다 쓰지 않는다)
- AI가 크게 틀렸거나, 엉뚱한 방향으로 갔다가 되돌아온 경험
- 처음 써 보는 도구, 엔진 기능을 AI와 함께 익힌 경험
- 지시 방식을 바꿨더니 결과가 확 달라진 경험 (→ `AGENTS.md` 반영)
- AI에게 맡기면 안 되는 일을 발견했을 때

목표: **한 사람당 주 1개 이상.** 짧아도 된다.

## 규칙
- 파일 이름: `YYYY-MM-DD-짧은-제목.md`
- `_template.md`를 복사해서 쓴다
- 솔직하게 쓴다. 실패 기록이 성공 기록보다 더 많은 것을 보여 준다.
- 관련 Issue/PR 번호를 꼭 연결한다 (근거가 되는 실제 기록이 있어야 함)
