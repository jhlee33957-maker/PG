## 2. 문제와 목표
- 문제: "AI로 만들었다"는 결과물만으로는 AI를 어떻게 다뤘는지 보여 줄 수 없다.
- 목표: 작업 과정(문제 정의 → 분업 → AI 활용 → 판단)이 저장소에 자연스럽게 남는 구조를 만든다.

## 3. 어떻게 쪼갰나
| 단위 | 담당 |
|---|---|
| 게임 컨셉 결정 (기획서 빈칸 채우기 플랫포머) | 사람 |
| 도구 선택 (Git + GitHub, SVN 대신) | 사람 (AI에게 비교 요청 후 결정) |

## 4. AI와 어떻게 일했나
- 먼저 인턴십 공고의 평가 역량(AI 리더십, 구조화 능력, 학습 실행력)을 공유하고, 이 역량이 기록으로 남는 저장소 구조를 요청했다.
- 그다음 게임 컨셉을 전달하고 Unity 기준의 설정 파일과 템플릿을 요청했다.
