# 게임 기획 (살아 있는 문서)

> 이 문서는 계속 바뀐다. 큰 방향이 바뀌면 `docs/decisions/`에 결정 문서를 따로 남기고 여기서 링크한다.
> 가제: 「커피 쏟은 기획서」 (미확정)

## 1. 한 줄 컨셉
커피를 쏟아 일부가 지워진 기획서. 개발자는 빈칸을 **제한된 선택지로 전부 채운 뒤** 플레이테스트해서 스테이지를 클리어해야 한다.

## 2. 핵심 루프
```
기획서 열람 → 지워진 칸 채우기 (제한된 선택지, 전부 채워야 함) → 빌드 & 플레이테스트
     ↑                                                        ↓
     └────────── 실패 시 원인을 보고 빈칸 수정 ←────────── 클리어 / 실패
```

## 3. 빈칸 유형
| 유형 | 예시 문장 | 선택지 예 |
|---|---|---|
| 수치 | 점프 높이는 [ ▒▒ ]이다 | 낮음 / 보통 / 매우 높음 |
| 대상 | [ ▒▒ ]은(는) 중력의 영향을 받지 않는다 | 플레이어 / 적 / 발판 |
| 조건 | 플레이어가 [ ▒▒ ]할 때 | 점프 / 착지 / 피격 |
| 효과 | ...[ ▒▒ ]한다 | 중력 반전 / 크기 2배 / 시간 정지 |

조건과 효과를 조합하면 예상 밖의 규칙이 만들어진다. 이 황당함이 게임의 핵심 재미다.

## 4. 기획서 훼손 종류 (스테이지 기믹 후보)
| 훼손 | 효과 | 버전 |
|---|---|---|
| 커피 얼룩 | 기본 빈칸 | v0.1 |
| 스테이플러 | 두 문장이 겹쳐 하나로 읽힘 | 이후 |
| 잉크 부족 | 글자가 흐려 선택지가 두 개로 보임 | 이후 |
| 메신저 "그거 빼주세요" | 문장 하나 삭제 | 이후 |

## 5. 아이디어 백로그 (v0.1 이후)
- **레거시 사양:** 이전 스테이지에서 채운 값이 다음 기획서에 "기존 사양 (변경 불가)"으로 굳어진다.
- **기획 의도 일치율:** 클리어 후 원본 기획서와 비교. "기획 의도와 23% 일치. ...근데 이게 더 재밌네?"
- **빌드 횟수 제한:** 테스트를 너무 많이 하면 "마감 임박" 연출.
- **자동 검증 툴:** 모든 빈칸 조합을 자동으로 돌려 클리어 가능 여부를 확인 (레벨 디자인 검증용 내부 툴).

## 6. v0.1 범위 (MVP)
**목표: 처음부터 끝까지 플레이할 수 있는 스테이지 3개.**

포함:
- 플랫포머 기본 조작 (이동, 점프), 가시, 순찰 적, 골인 지점
- 기획서 화면: 문장 표시, 커피 얼룩 빈칸, 선택지 고르기, 전부 채워야 "빌드" 가능
- 실패하면 기획서로 돌아가 수정, 클리어하면 다음 스테이지
- 규칙 5종 (아래)

제외 (v0.1에서는 하지 않음):
- 훼손 종류 2~4번, 아이디어 백로그 전부
- 사운드, 세이브, 메뉴 화면 (최소한만)

### v0.1 규칙 5종 (초안)
| # | 문장 | 유형 | 선택지 |
|---|---|---|---|
| R1 | 점프 높이는 [ ▒▒ ]이다 | 수치 | 낮음 / 보통 / 매우 높음 |
| R2 | 중력은 [ ▒▒ ]배이다 | 수치 | 0.5 / 1 / 2 |
| R3 | 적에게 닿으면 [ ▒▒ ] | 효과 | 플레이어 사망 / 튕겨 나감 / 적 사망 |
| R4 | 플레이어는 [ ▒▒ ]만큼 크다 | 수치 | 절반 / 보통 / 2배 |
| R5 | 플레이어가 [ ▒▒ ]할 때 [ ▒▒ ]한다 | 조건+효과 | 점프·착지·피격 × 중력 반전·크기 변경·잠깐 정지 |

### v0.1 스테이지 초안
| 스테이지 | 사용 규칙 | 의도 |
|---|---|---|
| 1 (튜토리얼) | R1 | 빈칸을 채우고 테스트하는 흐름 익히기. "매우 높음"은 천장 가시에 닿아 실패 |
| 2 | R2 + R3 | 두 빈칸의 조합. 적을 밟고 가야 하는데 중력에 따라 닿는 방식이 달라짐 |
| 3 | R4 + R5 | 조건+효과 규칙. 좁은 통로(크기) + 중력 반전으로만 갈 수 있는 천장 길 |
